      Backup

      Download a JSON snapshot of every user's settings and permissions before making bulk changes. Keep it somewhere safe — it is the only way to recover if a mass update goes wrong.

      Restore

      Upload a previously downloaded backup file to overwrite current settings with the values from the backup. Use this to undo a bad mass update. This is destructive — it replaces every matching user's configuration and permissions with what the backup contains.
